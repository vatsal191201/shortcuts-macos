KeyPeek is the new name of ShortCuts. Double-press ⌘ in any app to peek at its keyboard shortcuts.

## New

- **Search in plain words.** Type "refresh", "make text bigger" or "incognito". Word matches come first. A **Similar** section then shows commands with a similar meaning. A tiny model inside the app (5 MB, no network) finds them.
- **Safe first highlight.** A Similar row gets the first highlight only when the match is strong and the command is not in the Apple menu. Otherwise the highlight stays on "Show all shortcuts", so Return never runs a weak guess.
- **App icon.**
- **Apple Silicon and Intel.** One app runs on both.

## Fixes

- Settings no longer erase the use counts of your shortcuts.
- A future version that adds a setting keeps all your other settings.

## Install

1. Download `KeyPeek-0.3.0.zip`, open it, and move `KeyPeek.app` to Applications.
2. Open KeyPeek. macOS shows a warning, because the app is not notarized yet. Click **Done**.
3. Allow the app to open:
   - **macOS 15 or later:** open System Settings > Privacy & Security. Find the line about KeyPeek and click **Open Anyway**. Confirm with your password.
   - **macOS 13 or 14:** in Finder, Control-click KeyPeek, choose **Open**, then click **Open**.
4. Give Accessibility access: System Settings > Privacy & Security > Accessibility (on macOS 27, "Device Control and Data Access"). Turn on **KeyPeek**.
5. Double-press ⌘ in any app.

## Upgrade from ShortCuts 0.1.0 or 0.2.0

1. Quit ShortCuts and move `ShortCuts.app` to the Trash.
2. In the Accessibility list, remove the **ShortCuts** entry.
3. Install KeyPeek as above. On its first start, KeyPeek copies your ShortCuts settings.

After each future update, macOS asks for Accessibility access again, because the app does not have a Developer ID signature yet. Remove the old entry and turn on the new one.

## Build

GitHub Actions built this release from tag `v0.3.0`: all tests passed, and the app is universal (arm64 and x86_64). It is ad-hoc signed and not notarized. The SHA-256 of the zip is in `KeyPeek-0.3.0.zip.sha256`.
